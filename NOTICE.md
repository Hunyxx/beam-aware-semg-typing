# Attribution

This repository builds on Meta Platforms, Inc.'s
[emg2qwerty](https://github.com/facebookresearch/emg2qwerty), commit
`3200d91eeb952cbed1f278e47d0cc56928334fd1`.

The multi-scale CNN–Conformer, split-and-share encoder, auxiliary objectives,
beam-aware language-model corrector, and associated training and evaluation
tools implement “sEMG Typing Transcription with Conformer Encoding and
Beam-Aware Large Language Model Correction” by Yuanxi Wang, Lun Shu, and
Yasuharu Koike.
